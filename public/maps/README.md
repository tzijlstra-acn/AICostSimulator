# Map Data

Source: Natural Earth 110m Admin-0 Countries
URL: https://github.com/nvkelso/natural-earth-vector
License: Public Domain (https://www.naturalearthdata.com/about/terms-of-use/)
Coverage: EU-27 + UK + Switzerland + Norway + Iceland + Liechtenstein + adjacent context countries
Processing: Filtered and simplified from original 110m dataset
Last updated: 2026-08-22

Known limitations:
- 110m resolution (suitable for country-level visualization, not sub-national detail)
- Liechtenstein may require enlarged hit target due to small size
- Kosovo included as XK (disputed)

Update process: Re-run scripts/download-geo.mjs with the latest Natural Earth release
